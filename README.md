A university network designed and simulated using **Cisco Packet Tracer**.

* Inter-VLAN Routing
* DHCP & DNS
* Multiple departments
* Network security
* Server connectivity

### Tools

* Cisco Packet Tracer
* Cisco Routers & Switches
* PCs & Servers
